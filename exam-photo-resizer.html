How to prepare a photo or signature

The Exam Photo Resizer helps you crop an image to a chosen shape, calculate output pixel dimensions from centimeters and a DPI value, and export a JPEG while trying to meet a maximum file size. It is useful when you already know the requirements of an application form. It does not check those requirements for you or certify that a portal will accept the result.

Before loading a photo, read the instructions for the exact application you are completing. Write down its format, pixel dimensions or physical size, maximum and minimum file size, and any rules about background, framing, recency, or signatures. Different applications can use different rules even when they look similar.

Step 1: enter your own requirements

Choose one of the dimension presets only if it matches your instructions. Otherwise choose Custom size and enter the width and height in centimeters. The presets are convenient sizes, not official templates for a named exam or agency. Keep the width and height in the correct order; swapping them changes a portrait frame into a landscape frame.

Enter the DPI value used for the dimension calculation and the maximum file size in KB. The default values are starting points, not recommendations for every form. The tool shows the pixel dimensions before export so you can compare them against the form. If the form specifies pixels directly, use those pixels as the final check.

What the DPI field actually does

The calculation is pixels = centimeters ÷ 2.54 × DPI, rounded to a whole pixel. For example, 3.5 × 4.5 cm at 200 DPI becomes approximately 276 × 354 pixels. This example describes the calculation only; it is not a current requirement for any exam.

The DPI input determines the pixel dimensions. This tool does not write your chosen DPI into the JPEG’s resolution metadata. Browsers commonly export canvas images with 96 DPI metadata where supported, as described in the browser canvas export documentation. If a portal checks a metadata DPI value, use an editor that explicitly sets it and verify the resulting file.

Step 2: load and frame the image

Choose a clear source photo in a format your browser can open. The crop preview shows the part that will be retained. Drag the image underneath the frame to position the subject, then use the zoom slider if you need a tighter crop. Focus the preview and use the arrow keys for small positioning adjustments.

Keep any required parts of the subject inside the frame. For a signature, check the first and last strokes as well as the top and bottom. For a portrait, avoid trimming the subject just to remove empty space unless the application instructions allow that framing. This tool crops and resizes; it does not replace a background or repair an unsuitable source photo.

Step 3: export and inspect

Choose Crop, resize & download. The result panel reports the output dimensions, file size, and chosen compression quality. The tool tries several JPEG quality settings and keeps a suitable result when it can fit within your target. If it cannot, it displays a warning rather than guaranteeing success.

Open the downloaded JPEG before uploading it to the application portal. Inspect the eyes, hair edges, fine signature strokes, and any other details the form needs. A file can fit the size limit and still be too blurry to use. Keep your source photo so that you can make a fresh export instead of repeatedly compressing an already compressed copy.

File size and image dimensions are different

Pixel dimensions describe the image grid. File size describes how much storage the encoded image occupies. Two 276 × 354 images can have different file sizes because their textures, noise, backgrounds, and compression differ. Changing the filename or its extension does not alter either property in the way a portal expects.

The tool treats one KB as 1,024 bytes. A portal may report sizes using a different convention or round the display differently, so leave a little room below a maximum if the instructions permit. A maximum-size target also does not enforce a portal’s minimum-size requirement. Check both ends of an allowed range.

Why is the result still too large?

The allowed quality range may be unable to meet a very small target while keeping the selected dimensions. Start with a cleaner source if available. Reduce dimensions only when the application allows it; making a required image smaller can create a different rejection. If the source and requirements cannot work together here, use an editor with more explicit export controls.

Why does the portal reject a file that looks correct?

Check the actual file type, width, height, byte size, and any required metadata. Then review subject framing and the form’s own error message. A browser preview cannot determine every acceptance rule. This tool has no connection to the application portal and cannot submit or approve your image.

Where does my photo go?

Cropping and JPEG encoding run locally in your browser. Selecting a file does not upload it to a Broshere image-processing server. When you later upload the result to a form, that is a separate action on that service. For a practical final review, use the photo dimensions and file-size checklist.
