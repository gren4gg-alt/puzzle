Photo dimensions, DPI, and file size: a practical checklist

Understand the different requirements an upload form can impose, then inspect the file you actually download.

Separate the four measurements

A form can ask for an image format, pixel dimensions, physical dimensions, and a file-size range. These describe different properties. JPEG is a format; 276 × 354 describes a pixel grid; 3.5 × 4.5 centimeters describes a physical size; and 50 KB describes storage. Satisfying one does not automatically satisfy the others.

Copy the requirements from the exact form before editing. Check whether it specifies a maximum only or a minimum as well. Also record framing requirements that cannot be reduced to a number, such as a particular background or keeping a signature entirely visible. Broshere’s presets do not establish the requirements for any specific application.

Convert dimensions carefully

To calculate a pixel dimension from centimeters, divide by 2.54 to convert to inches, then multiply by DPI. The resizer rounds to whole pixels. For an illustrative 3.5 × 4.5 cm image at 200 DPI, this produces approximately 276 × 354 pixels. At 300 DPI, the same physical dimensions produce approximately 413 × 531 pixels.

The examples are calculations, not official photo standards. If a form already specifies exact pixel dimensions, compare the exported width and height directly with those values. Rounding can matter when a portal performs an exact check. Do not assume a familiar physical preset will necessarily produce the portal’s requested pixels.

Distinguish calculation from metadata

Resolution metadata is a value stored inside some image formats. It can influence how software interprets physical print size without changing the actual number of pixels. Changing metadata alone does not create extra detail or remove compression damage.

Broshere’s DPI field is used for the pixel calculation. Its JPEG export does not explicitly store that selected DPI as resolution metadata. Browser canvas exports use 96 DPI metadata for formats that support it, according to the canvas export documentation. A portal that checks embedded DPI may therefore need an additional export step in an editor that supports setting it.

Crop before judging the result

Start with a source that is clear and suitably framed. Drag it inside the crop preview and zoom only as much as necessary. Cropping chooses which part of the picture remains; resizing chooses how many pixels describe that part. Enlarging a tiny source cannot recover details that were never captured.

For a signature, inspect the outer strokes, not just the center. For a portrait, inspect the entire required area around the subject. If you have to crop away required content to fill the frame, use a different source rather than relying on export settings to fix the composition.

Meet size limits without losing clarity

JPEG compression trades some image information for a smaller file. More detailed or noisy pictures often require more storage than simple ones at the same dimensions. If a result is too large, compare a cleaner source or a different permitted quality setting before changing required dimensions.

The resizer tries to fit under your chosen maximum within its quality range. It may still return an oversized result with a warning. Inspect the reported size, then check it again in your file manager. The tool displays KB using 1,024 bytes per KB; other software may round differently or use decimal units.

A maximum-size control does not guarantee a minimum size. If the form permits 20–50 KB, a 12 KB output does not meet that range simply because it is below 50. Also, a correct extension is not proof of format conversion: renaming a PNG to .jpg does not encode a JPEG.

Inspect the final download

  1. Open the actual exported file, not only the page preview.
  2. Confirm the file type and exact width and height.
  3. Check the byte size against both ends of any permitted range.
  4. Check resolution metadata if the form explicitly requires it.
  5. Zoom in enough to inspect important details, then judge the whole composition.
  6. Read any portal error literally and compare it with the property it names.

Keep the source and a clearly named final export. Repeatedly compressing the last compressed copy can accumulate damage. If the portal still rejects the file, save its error message and recheck the exact instructions. The resizer can help prepare a file, but it cannot determine or guarantee the portal’s decision.
