About Broshere

Broshere is a small, independently built collection of browser-based web utilities and mini-games.

What Broshere does

Broshere focuses on simple tools that are useful for everyday tasks, creative projects, and quick experiments. The goal is to make these tools easy to use without requiring users to install software.

Privacy-first tools

Where a tool is designed for local browser processing, files, photos, or other input are processed directly in your browser rather than being uploaded to a Broshere server. The exact behavior of each tool is described on its individual page.

How Broshere is built

Broshere is maintained by one person. New tools and games are added when there is something useful or interesting to build, rather than on a fixed publishing schedule.

Tools with a clear purpose

Photo Puzzle Exchange turns a photo into a file another person can solve. Media Compressor helps compare smaller versions of images, audio, and video. Exam Photo Resizer provides a crop frame and dimension controls for preparing a JPEG. Model Workbench prepares 3D assets with conversion, compression, previews, and export reports. Its sample model lets visitors learn the controls before choosing a file. Each tool’s instructions describe what it can produce and what you still need to check.

Games with their own rules

Cozy Fit explores spatial packing through 50 shaped boards and hints that check the current arrangement. Word Fall rewards accurate word building and quick combos. ROLL focuses on distance and obstacle timing. Drift Hop explores moving-platform patterns over eight levels. Dune Runner combines route choice with shard collection in a 3D valley. The guide library explains these mechanics with examples so players can learn beyond the opening tutorial.

How content is checked

Guides are written for the behavior available on Broshere, including scoring examples and output limitations. Example photo dimensions are not presented as official requirements. If a game or tool changes, its instructions should change with it. Reports of inaccurate steps, missing words, broken downloads, or unclear controls help identify what needs attention.
